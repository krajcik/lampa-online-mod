# Online Mod Clean

## BWA Clean

Небольшое самостоятельное дополнение к обычному [BWA](https://bwa.ad/rc), версия 0.1.0:

```text
https://krajcik.github.io/lampa-online-mod/bwa-clean.js?v=0.1.0#
```

Оставьте обычный BWA включённым и добавьте эту ссылку отдельным расширением,
затем перезапустите Lampa. Сохраняйте завершающий `#`.
Online Mod Clean одновременно включать не требуется.

Дополнение удаляет VAST-поля из запусков и очереди BWA, подавляет преролл Lampa
через штатные события плеера. Не заменяет методы Player и не меняет глобальные
рекламные настройки. Ссылки, качество, субтитры, заголовки и проверки доступа
сохраняются. Серверные рекламные сегменты и вшитая реклама не удаляются.

Версия: Lampa Remote `settings get bwa_clean_version`.
Отключение: выключить BWA Clean и перезапустить Lampa.
Код дополнения собственный, MIT; BWA загружается отдельно с адреса автора.

Контракты проверены по Lampa source `71733ed` и BWA SHA256 `a57d8787df42b6dd95d690e4eebd41a37b14e97e9b7a6a36568b72cbcebad4f8`.
Тесты моделируют события плеера и проверку продолжения по идентичности объекта;
живая проверка на TV пока не завершена.

## Патч Online Mod

Небольшой патч [Online Mod от nb557](https://github.com/nb557/plugins), версия Clean 0.1.3.

- VAST-реклама не передаётся из Lumex Ads в плеер и очередь серий.
- Запуски этого плагина используют режим продолжения своего элемента плейлиста,
  чтобы Lampa не вставляла собственный преролл. Глобальные настройки рекламы не меняются.
  При автопереходе на следующую серию очередь восстанавливается только для элементов этого плагина.
- Filmix показывает качества, перечисленные самим источником, без клиентского
  ограничения по статусу аккаунта. Аварийный переход на низкое качество сохранён.
- Проверки аккаунта, токены и обработка серверных отказов сохранены. Доступность
  4K не гарантируется; вшитая в видео реклама не удаляется.

## Установить

Адрес для Lampa:

```text
https://krajcik.github.io/lampa-online-mod/online_mod.js?v=0.1.3#
```

В существующей регистрации Online Mod замените ссылку на эту и включите плагин.
Сохраните завершающий `#`: добавляемые Lampa данные аккаунта останутся в fragment.
Одновременно используйте одну версию Online Mod, затем перезапустите Lampa.
Настройки и история используют исходные ключи.
Загруженную версию можно прочитать через Lampa Remote: `settings get online_mod_clean_version`.

## Собрать и проверить

Нужен Node.js 22+, дополнительных зависимостей нет:

```sh
node build.mjs
node --check online_mod.js
node --test tests/*.test.mjs
```

Сборщик получает закреплённый исходник и проверяет SHA256 перед заменами.
Исходный коммит и хеш — в `upstream.json`. Для обновления требуется проверить
новый исходник и границы патча; автоматической подмены версии нет.
Тесты исполняют код провайдеров в VM с фиктивными ответами сервера.
Они не подтверждают реальный поток, HDR или отсутствие рекламы на всех источниках.

Исходный плагин принадлежит его авторам; лицензия в исходном репозитории не указана.

## Живая проба

На Philips Google TV / Android 12 / Lampa 3.3.8 проверены установка и маркер сборки.
В Filmix появились высокие качества, но проверенные фильм и сериал вместо полного
видео получили ролик с предложением PRO. Это серверное ограничение, а не рабочий 4K.
CDNVideoHub в этой пробе дал ошибку формата. Патч не гарантирует доступность источников.
В 0.1.2 отдельно проверен автопереход между двумя элементами без преролла Lampa;
0.1.3 дополнительно отклоняет некорректные и неподдерживаемые значения качества.
После пробы исходная регистрация Online Mod восстановлена и оставлена выключенной.
